# Introduction to Artificial Intelligence 20026/2027

This repository contains the tutoring material for the 2026/2027 Introduction to Artificial Intelligence at University of Studies of Trieste.

The repository is updated on a weekly basis.

Notice that each week the notebook for the week will be updated, together with the solution of the notebook for the previous week.

## Structure

```bash
root/
│
├── notebooks/            # Notebooks
    ├── lectures/         # Lectures' notebooks
    └── solutions/        # Solutions for lectures' notebooks  
├── resources/            # Additional resources for students
├── scripts/              # Python source code
└── README.md
```
